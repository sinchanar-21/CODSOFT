
# CodSoft Internship Projects – Web Development

This repository contains the projects I completed during my **CodSoft Web Development Internship**.  
Each project is built using **HTML, CSS, and JavaScript**, focusing on fundamentals, creativity, and user-friendly design.

---

## 📂 Projects Included

### 1. Personal Portfolio Website
A responsive portfolio showcasing my skills, projects, and resume.

**Features:**
- Header with name/logo and tagline
- About section with profile image and bio
- Skills section with key expertise
- Projects section with titles, descriptions, and images
- Resume download link (PDF)
- Contact section with email and phone details
- Modern CSS styling with hover effects

---

### 2. Landing Page Project
A beginner-friendly landing page designed with clean layouts and creative styling.

**Features:**
- Hero section with text + image
- Columns and divided sections using CSS Flexbox
- Features section with three cards
- Footer for branding
- Focus on alignments, padding, and color palette
- Responsive and visually appealing design

---

### 3. Basic Calculator
An interactive calculator built with HTML, CSS Grid, and JavaScript.

**Features:**
- Display screen for input and results
- Buttons for digits and operations (+, −, ×, ÷)
- Clear (C), Delete (DEL), and Equals (=) functionality
- CSS Grid for button alignment
- Event listeners and operators for calculations
- Error handling for invalid inputs

---

## 🚀 Tech Stack
- **HTML5** → Structure and content  
- **CSS3** → Styling, layouts, responsiveness  
- **JavaScript (ES6)** → Interactivity and logic
